# Discipline profiles for a full read

Profiles supply defaults, never a fixed template. Select in this order:

1. An explicit user choice.
2. The user's natural-language analysis focus.
3. Title, abstract, journal, and full text.
4. `general`.

Record one primary profile and only genuinely useful secondary profiles. Spend more analysis on user-requested dimensions and omit irrelevant defaults.

## `general`

Cover the core problem, background gap, approach, result, interpretation, contribution, robustness, limitations, and transferable lessons.

## `medicine`

Consider PICO or PECO, design, population, eligibility, sample size, intervention or exposure, comparator, endpoints, effect sizes, confidence intervals, statistics, loss to follow-up, confounding, bias, safety, clinical significance, external validity, registration, and ethics.

## `chemistry`

Consider the chemical system, route, reagents, stoichiometry, solvent, temperature, pressure, duration, yield, selectivity, characterization, kinetics, thermodynamics, mechanistic support, reproducibility, scale-up, safety, waste, and environmental impact.

## `materials`

Consider composition, phase, crystal structure, defects, surfaces, interfaces, microstructure, preparation, characterization, test conditions, performance, structure-property relations, stability, processability, manufacturability, cost, and baseline comparability.

## `catalysis`

Consider catalyst composition, active phase and sites, cocatalyst, support, preparation, reaction system and reactor, illumination or electrochemical conditions, sacrificial reagent, temperature, pressure, normalization, selectivity, stability, deactivation, kinetics, transport, charge transfer, adsorption, intermediates, mechanistic support, controls, operando characterization, and cross-paper comparability.

## `physics`

Consider the physical system, regime, assumptions, symmetries, model, governing equations, initial and boundary conditions, experimental or computational setup, observables, error bounds, scaling, approximations, limiting cases, theory-experiment agreement, numerical stability, and parameter sensitivity.

## `mathematics`

Consider problem definition, notation, assumptions, main theorem and strength, proof architecture, key lemmas, technical obstacles and innovations, relation to prior results, weakenable assumptions, generality, special cases, examples, counterexamples, open problems, constructiveness, and algorithmic implications.
