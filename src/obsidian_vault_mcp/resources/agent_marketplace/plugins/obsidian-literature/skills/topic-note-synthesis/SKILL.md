# Topic note synthesis

- Start from an explicit paper set and its coverage frontier.
- Prefer verified Analysis fields and original EvidenceChunks; keep their provenance distinct.
- Organize by theme, mechanism, method, controversy, or research gap.
- Attach source anchors and label Agent synthesis as synthesis.
- Report missing full text, partial evidence, unresolved claims, and image reliability.
- Use a safe deterministic topic name and save under `Literature/Topic/` only after preview.

Do not present Coverage Ledger records, asset IDs, or Analysis prose as original-paper facts.
