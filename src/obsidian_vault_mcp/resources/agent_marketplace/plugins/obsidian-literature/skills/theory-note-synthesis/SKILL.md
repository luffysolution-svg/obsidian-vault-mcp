# Theory note synthesis

Build sections for theory name, original definitions, constructs, variable relations, proposed mechanisms, boundary conditions, measurements, paper-specific variants, supporting evidence, opposing evidence, limitations, and source papers.

Every original definition needs an evidence anchor. Keep author proposals separate from demonstrated results and Agent synthesis. Preserve disagreements and incompatible variants rather than forcing them into one theory. Report whether each source is full-text, abstract-only, or unresolved.

Use a safe deterministic filename under `Literature/Theory/` and preview before writing.
